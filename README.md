# Operating systems course notes, modernized

This project updates the interface of John Bell's Operating Systems course notes for CS 385 at the University of Illinois Chicago.

## Objective

Make the original static notes easier to read and navigate on current desktop and mobile browsers. The shared interface adds a course map, chapter navigation, local chapter search, an outline, a reading-progress indicator, and a day and night theme.

## Scope and attribution

The academic material, figures, examples, and references belong to their original authors. In particular, the course notes are by John Bell. This repository does not claim authorship of that material, revise it, or replace it.

The work here is limited to the presentation layer in `assets/site.css` and `assets/site.js`. The original HTML documents remain the source content, and the interface continues to load their figures from the original course site.

## Running locally

Open `index.html` in a modern browser. The project has no build step or server-side dependency.
